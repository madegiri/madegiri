## About Me

I'm an **Informatics Engineering graduate from Politeknik Negeri Jakarta** with a focus on full-stack web development.

I have hands-on experience building and deploying web applications using **Laravel, PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript**. During my internship, I worked on production web systems, including attendance and recruitment platforms, while handling development, database management, deployment, and maintenance.

I also have experience as a **freelance developer**, independently delivering a company profile and product export website from requirements to deployment.

Previously, I participated in **Bangkit Academy 2024 Batch 2** as part of the Mobile Development learning path. I'm continuously learning new technologies and improving my skills to build reliable, maintainable, and user-focused digital solutions.
